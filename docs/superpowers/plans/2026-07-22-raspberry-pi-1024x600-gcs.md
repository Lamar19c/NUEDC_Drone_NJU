# 1024×600 Raspberry Pi GCS Adaptation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dedicated 1024×600 three-column GCS layout without changing the existing 640×480 drawer interface or the full desktop layout.

**Architecture:** Add one intermediate CSS media query between the existing base desktop styles and the `max-width: 700px` compact styles. Keep all behavior and markup unchanged; the new query only reduces side-panel density and makes each side panel independently scrollable. Extend the existing HTML contract tests, then validate breakpoint behavior in a real browser.

**Tech Stack:** Single-file HTML/CSS/JavaScript, Python `unittest`, Playwright/Chromium validation, Git.

### Task 1: Lock the intermediate responsive contract with a failing test

**Files:**
- Modify: `tests/test_gcs_bridge.py`
- Test: `tests/test_gcs_bridge.py`

- [ ] **Step 1: Add the failing intermediate-layout contract test**

Add this method to `GroundStationRegressionTests` after `test_compact_layout_contract_is_present`:

```python
def test_medium_layout_contract_is_present(self):
    html = self.html_source()
    marker = "@media (min-width: 701px) and (max-width: 1100px)"
    self.assertIn(marker, html)
    start = html.index(marker)
    end = html.index("@media (max-width: 700px)", start)
    medium_css = html[start:end]
    self.assertIn("#left-panel, #right-panel", medium_css)
    self.assertIn("width: 220px", medium_css)
    self.assertIn("min-width: 220px", medium_css)
    self.assertIn("overflow-y: auto", medium_css)
    self.assertIn("overscroll-behavior: contain", medium_css)
```

### Task 2: Implement the 1024×600 three-column layout

- [ ] **Step 1: Add the intermediate media query**

Insert this CSS before the existing compact media query:

```css
@media (min-width: 701px) and (max-width: 1100px) {
  #left-panel, #right-panel {
    width: 220px;
    min-width: 220px;
    overflow-y: auto;
    overscroll-behavior: contain;
  }
  .panel h3 { padding: 7px 9px; font-size: 12px; }
  .section { padding: 7px 9px; }
  .section label { margin: 4px 0 2px; }
  .section select, .section input { padding: 4px 6px; }
  .btn { padding: 5px 8px; }
  .btn-group { gap: 3px; margin-top: 6px; }
  #telemetry-bar { gap: 4px; padding: 4px 6px; }
  .telem-item { padding: 2px 5px; }
  #right-panel .section[style] {
    flex: 0 0 auto !important;
    overflow: visible !important;
  }
}
```

Do not change markup, JavaScript command handlers, or the existing `max-width: 700px` rules.

({
