# UWB 零配置定位 — 设计文档

## 概述

消除 `uwb_config.json` 的强制手动填写，改为自动发现 + 一键标定。配置文件退化为可选覆盖层，字段全部可省略。

## 目标

- **首次部署**：只跑一次 `--calibrate`，其余自动
- **日常使用**：`python uwb.py` 直接启动，零配置
- **旧兼容**：已有 `uwb_config.json` 的字段作为覆盖值，优先级高于自动检测

## 自动发现

### 1. 串口

枚举所有可用串口，依次发送 `\r\n` 唤醒，读取响应。收到 `$DIST,` 行即确认为 UWB 设备。

- 波特率自动尝试：921600 → 115200 → 57600 → 19200 → 38400 → 9600 → 230400
- 命令行可覆盖：`--port COM3`、`--baud 19200`
- 发现失败则打印已尝试的端口列表及具体失败原因

### 2. 锚点标定

```
python uwb.py --calibrate
```

进入交互式菜单，三种标定方式可选：

```
==================================================
  UWB 锚点标定
==================================================

  选择标定方式:
    1. 步长标定 — 移动标签并测量实际距离
    2. 已知点位标定 — 将标签放在场地已知坐标点
    3. 直接输入锚点坐标（跳过测量）

  请输入 [1/2/3]:
```

**模式 1 — 步长标定**：标签放原点 → 沿 X 方向移动任意距离 → 沿 Y 方向移动任意距离，提示用户输入实际测量距离，不再强制 1m。勾股定理反算锚点坐标。

**模式 2 — 已知点位标定**：标签依次放在 N≥3 个已知坐标点（如场地网格交点、标记点），输入坐标，系统用最小二乘法反算每个锚点位置。适用于比赛场地有已知标记的场景。

**模式 3 — 直接输入**：跳过测量，直接手填锚点坐标。适用于已知场地大致锚点位置的情况。

非交互式调用：

```
python uwb.py --calibrate --cal-points "0,0,0;1.5,0,0;0,2,0;1.5,2,0"
python uwb.py --set-anchors "0,0,1.5;2,0,1.5;0,2,1.5;2,2,1.5"
```

### 3. 输出通道自动路由

| 通道 | 策略 |
|------|------|
| terminal | 始终开启 |
| UDP | 启动时尝试 UDP ping GCS 端口，收到响应则启用 |
| MAVLink | 检测飞控 heartbeat 是否存在，有则启用并读取 home 位置 |

失败不阻塞启动，仅打印状态。可命令行覆盖：
- `--no-udp` 强制关闭 UDP
- `--no-mavlink` 强制关闭 MAVLink
- `--mavlink-host 192.168.1.100:14550` 指定飞控地址

### 4. EKF Origin

MAVLink 通道启用后，等待 `HOME_POSITION` (#242) 或 `GLOBAL_POSITION_INT` (#33) 消息获取飞控 home 位置作为 EKF 原点。不再手填 E7 坐标。

## 配置文件（可选覆盖）

标定结果直接写入 `uwb_config.json` 的 `anchors` 字段（同时缓存到 `~/.uwb_calib.json` 作为后备）。用户也可手动编辑配置文件覆盖任意项：

```json
{
  "serial_port": "/dev/ttyUSB1",
  "baud_rate": 115200,
  "anchors": {
    "S1": [0.0, 0.0, 2.87],
    "S2": [3.46, 0.0, 2.90],
    "S3": [0.0, 3.96, 2.88],
    "S4": [3.46, 3.96, 2.91]
  },
  "output": {
    "terminal": true,
    "udp": { "enabled": true, "host": "127.0.0.1", "port": 14550 },
    "mavlink": { "enabled": false }
  }
}
```

所有键均为可选——空 `{}` 即表示完全自动。配置文件中的值优先级高于自动检测结果。

## 优先级链

```
命令行参数 > uwb_config.json > 缓存文件 (~/.uwb_calib.json) > 自动检测
```

## 文件变更

| 文件 | 变更 |
|------|------|
| `UWB/uwb.py` | 新增 `--calibrate`（交互式三选一标定）、`--cal-points`（非交互点位标定）、`--set-anchors`（直接设置锚点）、自动串口发现（7波特率+详细输出）、三点/多点标定引导、输出通道自动路由、MAVLink home 读取 |
| `gcs_bridge.py` | `load_uwb_config()` 改为加载 `~/.uwb_calib.json` 或 `uwb_config.json` 锚点数据 |
| `UWB/uwb_config.json` | 所有字段改为可选，加注释说明 |

## 兼容性

- 已有 `uwb_config.json` 继续正常工作——字段存在则使用，不存在则自动检测
- 命令行 `--port`、`--baud` 参数保持不变
- `gcs_bridge.py` 的 `get_config` 命令行为不变
