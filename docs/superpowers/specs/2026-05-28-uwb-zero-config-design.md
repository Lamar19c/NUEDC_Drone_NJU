# UWB 零配置定位 — 设计文档

## 概述

消除 `uwb_config.json` 的强制手动填写，改为自动发现 + 一键标定。配置文件退化为可选覆盖层，字段全部可省略。

## 目标

- **首次部署**：只跑一次 `--calibrate`，其余自动
- **日常使用**：`python uwb.py` 直接启动，零配置
- **旧兼容**：已有 `uwb_config.json` 的字段作为覆盖值，优先级高于自动检测

## 自动发现

### 1. 串口

枚举所有可用串口，依次发送 `\r\n` 唤醒，读取响应。收到 `$DIST,` 行即确认为 UWB 设备。

- 波特率自动尝试：19200 → 115200 → 57600
- 命令行可覆盖：`--port COM3`、`--baud 19200`
- 发现失败则打印「未找到 UWB 设备」及已尝试端口列表

### 2. 锚点标定（三点法）

```
python uwb.py --calibrate
```

M1 依次放三个位置，终端引导：

```
=== UWB 锚点标定 ===

[步骤 1/3] 将 M1 放在地面原点 (0, 0, 0)，按 Enter 确认...
  读取中... S1=2.87m S2=3.91m S3=4.52m S4=5.12m ✓

[步骤 2/3] 将 M1 沿 X 轴向前移动 1 米到 (1, 0, 0)，按 Enter 确认...
  读取中... S1=2.88m S2=3.55m S3=4.53m S4=4.78m ✓

[步骤 3/3] 将 M1 沿 Y 轴向右移动 1 米到 (0, 1, 0)，按 Enter 确认...
  读取中... S1=2.87m S2=3.92m S3=4.18m S4=4.45m ✓

✓ 标定完成，锚点坐标：
  S1: ( 0.00,  0.00,  2.87)
  S2: ( 3.46, -0.02,  2.90)
  S3: ( 0.01,  3.96,  2.88)
  S4: ( 3.46,  3.96,  2.91)
```

每步取多个距离读数取均值，抑制瞬时波动。

#### 解算公式

对每个锚点 i，三次测量：

- (0, 0, 0) → dᵢ⁰
- (Δx, 0, 0) → dᵢˣ
- (0, Δy, 0) → dᵢʸ

```
xᵢ = (dᵢ⁰² − dᵢˣ² + Δx²) / 2Δx
yᵢ = (dᵢ⁰² − dᵢʸ² + Δy²) / 2Δy
zᵢ = √(dᵢ⁰² − xᵢ² − yᵢ²)
```

Δx、Δy 默认 1.0m，可通过 `--step` 调整（如场地受限可用 0.5m）。

### 3. 输出通道自动路由

| 通道 | 策略 |
|------|------|
| terminal | 始终开启 |
| UDP | 启动时尝试 UDP ping GCS 端口，收到响应则启用 |
| MAVLink | 检测飞控 heartbeat 是否存在，有则启用并读取 home 位置 |

失败不阻塞启动，仅打印状态。可命令行覆盖：
- `--no-udp` 强制关闭 UDP
- `--no-mavlink` 强制关闭 MAVLink
- `--mavlink-host 192.168.1.100:14550` 指定飞控地址

### 4. EKF Origin

MAVLink 通道启用后，等待 `HOME_POSITION` (#242) 或 `GLOBAL_POSITION_INT` (#33) 消息获取飞控 home 位置作为 EKF 原点。不再手填 E7 坐标。

## 配置文件（可选覆盖）

自动检测的结果缓存到 `~/.uwb_calib.json`（锚点坐标）和运行环境变量（串口）。用户可在 `uwb_config.json` 中手动覆盖任意项：

```json
{
  "serial_port": "/dev/ttyUSB1",
  "baud_rate": 115200,
  "anchors": {
    "S1": [0.0, 0.0, 2.87],
    "S2": [3.46, 0.0, 2.90],
    "S3": [0.0, 3.96, 2.88],
    "S4": [3.46, 3.96, 2.91]
  },
  "output": {
    "terminal": true,
    "udp": { "enabled": true, "host": "127.0.0.1", "port": 14550 },
    "mavlink": { "enabled": false }
  }
}
```

所有键均为可选——空 `{}` 即表示完全自动。配置文件中的值优先级高于自动检测结果。

## 优先级链

```
命令行参数 > uwb_config.json > 缓存文件 (~/.uwb_calib.json) > 自动检测
```

## 文件变更

| 文件 | 变更 |
|------|------|
| `UWB/uwb.py` | 新增 `--calibrate`、自动串口发现、三点标定引导、输出通道自动路由、MAVLink home 读取 |
| `gcs_bridge.py` | `load_uwb_config()` 改为加载 `~/.uwb_calib.json` 或 `uwb_config.json` 锚点数据 |
| `UWB/uwb_config.json` | 所有字段改为可选，加注释说明 |

## 兼容性

- 已有 `uwb_config.json` 继续正常工作——字段存在则使用，不存在则自动检测
- 命令行 `--port`、`--baud` 参数保持不变
- `gcs_bridge.py` 的 `get_config` 命令行为不变
